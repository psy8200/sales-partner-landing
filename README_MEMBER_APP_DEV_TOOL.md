# 📱 회원페이지 앱 개발 도구

네이티브 앱 개발을 위한 실시간 미리보기 및 테스트 도구입니다.

## 🎯 주요 기능

### 1. **iframe으로 회원페이지 로드** ✅
- 실제 회원페이지를 iframe으로 로드
- 실시간 콘텐츠 업데이트
- 보안을 위한 sandbox 속성 적용

### 2. **실제 스마트폰 해상도로 표시** ✅
- iPhone, Galaxy 등 실제 디바이스 해상도 지원
- 정확한 픽셀 단위 표시
- 실제 디바이스와 동일한 비율

### 3. **다양한 디바이스 프레임 선택** ✅
- **iPhone 시리즈**: iPhone 15 Pro, iPhone 15, iPhone SE
- **Galaxy 시리즈**: Galaxy S24, Galaxy S24 Ultra, Galaxy A54
- **태블릿**: iPad, iPad Pro
- 각 디바이스별 노치, 홈 인디케이터 지원

### 4. **실시간 새로고침 기능** ✅
- 원클릭 새로고침
- 로딩 상태 표시
- 자동 로딩 완료 감지

### 5. **반응형 디자인 테스트 도구** ✅
- 브레이크포인트 테스트 (Small, Medium, Large)
- 테마 테스트 (라이트, 다크 모드)
- 테스트 시나리오 (로그인, 에러, 로딩 상태)

## 🛠️ 개발 도구 기능

### **컨트롤 패널**
- URL 직접 입력 및 수정
- 빠른 액션 버튼 (홈페이지, 로그인, 회원가입, 프로필)
- 실시간 새로고침
- 디바이스 회전 (세로/가로)
- 온라인/오프라인 상태 표시

### **디바이스 프레임**
- 실제 디바이스와 동일한 외관
- 노치 및 홈 인디케이터 표시
- 회전 시 자동 레이아웃 조정
- 태블릿의 경우 적절한 스케일링

### **반응형 테스트**
- 다양한 화면 크기에서의 레이아웃 확인
- 테마별 UI 테스트
- 다양한 사용자 시나리오 테스트

## 🔧 사용 방법

### 1. **디바이스 선택**
- 좌측 컨트롤 패널에서 원하는 디바이스 선택
- 각 디바이스별 실제 해상도로 표시

### 2. **URL 설정**
- 기본값: `/member`
- 직접 입력 또는 빠른 액션 버튼 사용
- 쿼리 파라미터로 테스트 조건 설정

### 3. **테스트 실행**
- 반응형 테스트 도구로 다양한 조건 테스트
- 실시간 새로고침으로 변경사항 확인
- 디바이스 회전으로 레이아웃 테스트

### 4. **결과 확인**
- 실제 디바이스와 동일한 환경에서 확인
- 다양한 해상도에서의 반응형 동작 확인
- 테마별 UI 확인

## 🚀 개발 워크플로우

1. **개발**: 회원페이지 코드 수정
2. **테스트**: 개발 도구에서 실시간 확인
3. **반응형 검증**: 다양한 디바이스에서 테스트
4. **테마 테스트**: 라이트/다크 모드 확인
5. **시나리오 테스트**: 다양한 사용자 상황 확인
6. **배포**: 검증 완료 후 배포

## 📊 성능 최적화

- **iframe 최적화**: 필요한 권한만 허용
- **로딩 상태 관리**: 사용자 경험 향상
- **메모리 관리**: 효율적인 리소스 사용
- **반응형 렌더링**: 빠른 화면 전환

## 🔒 보안 고려사항

- **sandbox 속성**: iframe 보안 강화
- **CSP 정책**: 콘텐츠 보안 정책 적용
- **XSS 방지**: 안전한 콘텐츠 로딩
- **CSRF 보호**: 요청 위조 방지
